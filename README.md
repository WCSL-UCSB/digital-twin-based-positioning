# Digital Twin–Based Wireless Positioning

A research pipeline for 3D scene generation, radio propagation simulation, and wireless positioning using Sionna RT.

**Scenes:** Geo2SigMap/OpenStreetMap, Overture height fallback, LiDAR/DEM terrain, BostonTwin, or an existing Mitsuba XML scene.

**Pipeline:** scene → transmitter/receiver placement → ray tracing → path refinement and link budget → channel taps → beam-delay fingerprints → positioning.
