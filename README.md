# Digital Twin–Based Wireless Positioning

A pipeline for 3D scene generation, radio propagation simulation, and wireless positioning using Sionna RT.

**Status:** Public release in preparation. Code, installation instructions, and runnable examples will be added here.

**Planned scene-generation options:** Geo2SigMap with OpenStreetMap; LiDAR and DEM terrain; Geo2SigMap with Overture building-height fallback; BostonTwin; or an existing Mitsuba XML scene.

**Pipeline:** scene → transmitter/receiver placement → ray tracing → path refinement and link budget → channel taps → beam-delay fingerprints → positioning.

The release will include source attribution and dependency details alongside the code.
